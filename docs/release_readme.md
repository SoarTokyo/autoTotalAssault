# 蔚蓝档案战斗录制与技能轴复现

Windows 11 源码运行包，使用普通截图和键鼠输入，支持战斗视频录制、离线分析、技能轴编辑与复现。

仅面向总力战、大决战的模拟战及其他不产生或影响排名的模式。请遵守适用的《服务条款与最终用户许可协议》、游戏运营政策和最新公告。本项目未获针对本工具的官方许可确认，非排名用途及普通键鼠输入不代表已获许可或没有账号风险；规则禁止或无法确认允许自动化时，请勿启用自动输入。详见 README 与用户手册中的声明。

从安装到实际操作的完整教程见根目录的[用户使用说明](../用户使用说明.md)。本文件侧重运行环境与部署。

## 安装与启动

将压缩包完整解压到自己有写入权限的目录，双击 `start_gui.cmd`。启动器会检查项目环境；首次缺少 Python 时会调用安装脚本，缺少依赖或版本不符时会自动安装。安装过程中显示进度，失败时保留窗口；诊断记录在 `logs/environment-*.log`，界面自身错误在 `logs/gui-startup-*.log`。

也可在解压目录打开 PowerShell，手动配置：

```powershell
powershell -ExecutionPolicy Bypass -File tools/setup.ps1 -WithGui
```

本包没有附带 Python 环境。首次安装需要联网；环境正常时不会调用 pip 安装或升级。不能直接复制其他电脑的 `.venv`。如果已有环境无法运行，先关闭程序，将 `.venv` 重命名为 `.venv.old`，再双击启动；不需要删除录制和技能轴。

启动必需依赖：`mss`、`pynput`、`pywin32`、`opencv-python`、`numpy`、`jsonschema`、`PySide6`、`av`，以及由 pip 自动解析的间接依赖。版本范围以 `pyproject.toml` 为准。`windows-capture` 为可选后端，默认 mss 流程无需安装；无需另装 FFmpeg 命令行工具或系统 OCR。

只检查环境而不启动界面：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start_gui.ps1 -CheckOnly
```

## 换机器时的注意事项

- 使用 Windows 11 与 64 位 Python。过新的解释器可能尚无某些依赖的 wheel，安装失败会明确报错；脚本不会尝试在用户电脑编译原生库。
- 从压缩包内直接运行、放在无写权限的目录、磁盘不足，都会影响安装与保存。建议使用用户目录下路径较短的独立文件夹。
- 代理、证书、网络限制和安全软件可能阻止下载或运行。安装失败后修正对应问题，再启动即可；不要关闭证书校验。
- 若出现 DLL 加载错误，查看日志中具体组件。可能需要修复 Python 环境或安装微软 Visual C++ x64 运行库；启动器不会擅自安装系统运行库。
- 工具与游戏的权限级别应一致。游戏以管理员身份运行而工具权限较低时，普通输入可能无法送达；优先让两者都以普通权限运行。
- 当前支持窗口化、16:9、繁体中文标准 HUD，另行准备的默认视觉配置可跨设备沿用，不需按电脑重新制作；换机后先做短录制核对。
- 公开包不含游戏识别模板、字形、学生图片与特殊素材，取得合法来源的兼容素材后按手册第三章放置。

依赖版本范围尚未等同于所有版本组合都经过实测。当前仍需在全新 Windows 环境验证首次下载安装、不同显示缩放及权限场景；发布前应补充这项验证。

## 使用

- 录制页选好游戏窗口、录制文件名，切回游戏按 F8 开始；也可点开始录制按钮。初始化完成后自动采集。
- F9 停止并保存，F7 丢弃当前段并重启录制。按键可在键位设置里修改。
- 保存目录默认为 `recordings`，可保留中文录制名；同名会话不覆盖。
- 自动分析前选定六人队伍，生成的技能轴保存到 `scripts`。核对后保存，再从复现页执行。
- 选人目录包含未下载的学生；确认后在后台只补齐所选队伍的缺图。特殊素材缺失会提示后继续分析，无法确认的阶段不自动认定成功。
- 复现按 F8 启动／继续，F9 停止；失焦会暂停或停止输入。

录制无需角色素材。合法取得的兼容素材应将 `profiles` 与 `.local` 目录放到项目根目录，默认视觉配置位于 `profiles/local-steam-tw-v4-roster/`，程序自动选用。学生图库位于 `.local/gamekee/students`，特殊技能素材和补充字形分别位于 `.local/special-skills/packs`、`.local/hud-glyphs`。源码与素材分开提供不等于授予素材分发权，网盘和群内分享也需确认相应权利。仅支持单世界线，不支持依赖 Boss 随机技能、学生随机走位等随机行为或分支的轴；新角色和阶段仍需人工核对。

依赖由 `requirements-win64.lock.txt` 固定为当前验收的 Windows x64 运行库版本，安装与启动修复使用同一锁定文件。Python、pip、隔离构建工具及 wheel 哈希未锁定；开发者手动执行不带锁定文件的 pip 命令不在这一保证范围内。

特殊技能素材现在支持用户自截图制作：参照[制作指南](特殊技能素材制作指南.md)，将素材统一登记在 `.local/special-skills/packs/<学生英文短名>/`。源码包提供文字截图计划和 `tools/manage_skill_library.py`，不提供图片。制作后先校验，再用新录制检查实际识别效果。

学生图库来源为 [GameKee 蔚蓝档案 Wiki](https://www.gamekee.com/ba/second/23941)，感谢维护者与贡献者。本项目维护者已就此下载方式与 Wiki 维护方沟通并获得同意；请保持双方沟通过的低频、分批方案，尊重限流及后续站点要求。该同意仅针对下载方式，不代表游戏官方认可、图片再分发或其他站点授权。多形态技能素材库的公开获取方案仍待完善。以下是单条目调用示例：

```powershell
.\.venv\Scripts\python.exe tools/download_gamekee_students.py --limit 1 --batch-size 1 --batch-delay 30 --request-delay 3
```

本示例仅请求目录中的一个条目，不保证对应实际队伍。图片按英文名称及服装／形态命名；陌生角色缺少英文名称时会提示补充索引。实际使用请按需获取队伍素材，沿用已沟通的下载方式，遵守站点规则和素材权利要求，不扩大同意范围。

本包只提供 `scripts/tor格里高利礼奈春锅轴4001w.json` 这一份技能轴 demo，编队与起始手牌见用户手册第九章。请另存副本、核对条件后使用，不承诺文件名中的分数。开发测试、诊断脚本、个人配置、原始录制、其他个人技能轴、分析结果与日志不随包发布。第三方依赖说明见 `THIRD_PARTY_NOTICES.md`，发布前剩余事项见[发布前检查](发布前检查.md)。
