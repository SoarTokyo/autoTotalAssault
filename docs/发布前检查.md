## 生成运行包

完整开发工作区先运行测试，再构建；公开的精简仓库不包含 `tests`，可直接运行第二条打包命令。ZIP 运行包不包含开发测试和构建工具。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe tools/build_release.py
```

构建结果在 `dist`，包含 ZIP 和逐文件 SHA-256 清单。构建会拒绝覆盖旧包；请只上传最终选定的版本，不要整目录上传旧 ZIP。存在上述未完成事项时，生成包仅表示产物可审查，不表示已经适合正式发布。
