# 蔚蓝档案战斗录制器

面向 Windows 11 与《蔚蓝档案》Steam 国际服的战斗录制、技能轴编辑和复现工具，仅用于总力战、大决战的模拟战及其他不产生或影响排名的模式，供个人记录、离线分析与练习研究，不应用于排名结算、竞争性成绩提交或获取不公平优势。

使用流程：**录制 → 本地分析 → 人工核对与编辑 → 复现 → 查看证据并调整**。目标是辅助调整自己的技能轴，不是自动寻找最优策略。

## 当前版本

`0.1.0`，持续开发中的源码运行版本。

- 中文双标签页界面，启动前检查依赖，缺少环境或运行库时自动配置。
- 游戏窗口输入与连续视频录制，5／10／20／30 FPS 可选，支持热键开始、保存及丢弃当前片段后重录。
- 本地确定性分析，无需大模型；选定六人后自动补下载缺少的普通图片，再结合时间、费用、换牌和特殊技能素材取证。特殊素材缺失时提示并继续，无法确认的阶段留待核对。
- 表格编辑技能时间、身份、卡槽、释放时费用和目标，支持新增、删除、忽略、保存与另存为。
- 根据战斗倒计时预测施放，支持“秒接上个”“严格卡点”、失焦保护、停止热键及执行证据日志。
- 记录并复现 AUTO 开关，通过画面确认状态；AUTO 技能仅保留观察记录，由游戏自行选取目标。支持人工核对后启用转场跳过行，新增自动输入仍需实测。见[转场与 AUTO 分析说明](docs/转场与AUTO录制分析.md)。

代码与游戏识别素材分开提供；合法取得兼容素材后沿用同一套默认视觉配置，当前支持窗口化、16:9、繁体中文标准 HUD，无需按电脑重新校准。素材获取和放置步骤见手册第三章。仅支持单世界线录制与复现，暂不支持依赖 Boss 随机技能、学生随机走位等随机行为或分支的轴。复现执行技能、AUTO 状态控制及转场，不自动重放菜单、倍速等全部原始操作，也不追踪移动目标。

特殊技能素材可按[自截图制作指南](docs/特殊技能素材制作指南.md)在本地建立。公开包提供每名学生的文字截图计划、裁剪和校验工具，不包含素材图片；新增学生通过声明式清单登记，已采集名单不代表国际服全量支持。

## 开始使用

完整解压后双击 `start_gui.cmd`，首次配置需要联网。录制前设置好游戏窗口、名称和键位；分析、复现前准备相应素材并人工核对。

随包仅提供一份已录技能轴示例：`scripts/tor格里高利礼奈春锅轴4001w.json`。请先另存副本并核对适用条件；文件名不构成分数保证，使用仍限于规则允许的非排名练习场景。

demo 的编队、起始带牌与美祢练度建议见手册第九章。莉音复制卡按原卡身份与蓝框状态分别识别，不要求复制卡美术模板，也不把它当作新增学生形态；不清晰的画面仍会待确认。

**完整操作教程：[用户使用说明](用户使用说明.md)**，也可阅读根目录的 [Word 版本](用户使用说明.docx)。手册包含首次安装、素材准备、界面各项含义、录制与分析、轴编辑、复现、文件管理和常见问题。部署细节见[运行环境说明](docs/release_readme.md)。
